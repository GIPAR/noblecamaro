SMART CAMARO
Projeto em desenvolvimento que busca implementar navegação autônoma no robô Camaro, um veículo com direção Ackermann voltado para delivery, utilizando ROS2 Jazzy e Gazebo Harmonic

O projeto inclui a simulação completa do robô com SLAM e navegação autônoma via Nav2
Abra "Simulação.md" para ler o tutorial de como utilizar a simulação
O robô físico utiliza câmera, radar e LiDAR — a integração dos sensores reais está planejada para etapas futuras
Por utilizar direção Ackermann, o projeto possui desafios e soluções de navegação distintos dos robôs diferenciais
